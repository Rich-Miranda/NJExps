# NJExps
Site de informações sobres os jogos mais recente do mercado. Objetivo dele, mostrar as demais informações de jogos e caracteresticas referente ao games mundialmente conhecido pelo jogadores ao redor do mundo.
A cada iteração com os games fornecidos, aprenderá novas historias, informações, dicas referente ao jogo escolhido / Auto ajuda para guiar como jogar.

## Como rodar o projeto

Para rodar o projeto você pode rodar o comando :
- git clone https://github.com/Rich-Miranda/NJExps.git 

 - E no terminal ir até a pasta a qual está executando o projeto, e dar o comando :
   - cd NJExps
   - code .
           
## Ferramentas
 - Bootstrap para tranformar os layouts desenvolvido em responsivos
 - HTML & CSS A fins de otimizar/ criar itens que bootstrap não fornece
 - JS para interação de carrousel
